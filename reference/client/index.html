Client

Provides a client for the Halo Infinite API.

HaloInfiniteClient(spartan_token, clearance_token=None, max_retries=2, requests_per_second=5, session=None)

A client for the Halo Infinite API.

Parameters:

Name Type Description Default
spartan_token str | TokenProvider

The Spartan token used to authenticate with the API. Can be a token string or a TokenProvider instance for automatic token refresh support.

 required
clearance_token str | None

The clearance token used to authenticate with the API. Optional, but required for economy endpoints (get_player_customization, get_player_career_rank, get_player_reward_track_operations). Defaults to None.

 None
max_retries int

The maximum number of times to retry a request on failure.

 2
requests_per_second float

The rate limit to use. Note that this rate limit is enforced per service, not globally. Defaults to 5 requests per second.

 5
session ClientSession | CachedSession | None

The aiohttp.ClientSession to use. Support for caching is available via a CachedSession from aiohttp-client-cache. If not provided, one will be created when entering the client as an async context manager. Defaults to None.

 None

clearance_token property

Get the current clearance token.

spartan_token property writable

Get the current spartan token provider.

__aenter__() async

Enter async context manager.

__aexit__(exc_type, exc_val, exc_tb) async

Exit async context manager and close internally managed session.

get_service_record(player, match_type='matchmade', season_id=None, game_variant_category=None, is_ranked=None, playlist_asset_id=None, gameplay_interaction=None) async

Get a service record for a player. Summarizes player stats.

Note that filters (season_id, game_variant_category, is_ranked, and playlist_asset_id) are only applicable to "matchmade" match_type. A warning is issued and the filters are ignored if they are provided for a non-matchmade match_type.

Filters must be combined appropriately. The following are valid:

  • season_id
  • season_id, game_variant_category
  • season_id, game_variant_category, playlist_asset_id
  • season_id, game_variant_category, is_ranked
  • season_id, playlist_asset_id
  • season_id, gameplay_interaction
  • game_variant_category
  • game_variant_category, is_ranked

To collect possible values for the filter arguments, look at the "subqueries" attribute of an unfiltered service record response.

Parameters:

Name Type Description Default
player str | int

Xbox Live ID or gamertag of the player to get counts for. Examples of valid inputs include "xuid(1234567890123456)", "1234567890123456", 1234567890123456, and "MyGamertag".

 required
match_type ServiceRecordMatchType

The type of games to include in the service record. One of "matchmade", "custom", or "local".

 'matchmade'
season_id str | None

The season ID to get service record for. Optional.

 None
game_variant_category GameVariantCategory | int | None

The game variant category to filter service record data. See spnkr.parsers.refdata.GameVariantCategory for human-readable values. Optional.

 None
is_ranked bool | None

Filter for ranked or unranked games. Optional.

 None
playlist_asset_id str | UUID | None

Filter for a specific playlist with its asset ID. Optional.

 None
gameplay_interaction GameplayInteraction | None

Filter for a specific gameplay interaction (e.g., PVP).

 None

Returns:

Type Description
ServiceRecord

The service record for the player with the given filters.

Raises:

Type Description
ValueError

If match_type is not one of "matchmade", "custom", or "local".
ValueError

If filter arguments are inappropriately combined.
